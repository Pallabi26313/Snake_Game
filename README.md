# 🐍 Snake Game

A classic Snake Game built using C++. The player controls the snake to eat food, grow longer, and achieve the highest possible score while avoiding collisions.

---

## 📌 Project Overview

This project is a console-based implementation of the traditional Snake Game.
The objective of the game is to control the snake, collect food, and prevent it from colliding with walls or itself.

It demonstrates core programming concepts such as:

* Loops
* Conditional statements
* Functions
* Arrays
* Game logic implementation

---

## 🚀 Features

* 🎮 Real-time keyboard controls
* 🍎 Random food generation
* 📈 Score tracking
* 💀 Game over on collision
* 🔄 Continuous snake movement

---

## 🛠️ Technologies Used

* **C++**
* Standard Library
* Console-based graphics

## ▶️ How to Run the Project

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/Pallabi26313/Snake_Game.git
```

### 2️⃣ Navigate to Project Folder

```bash
cd Snake_Game
```

### 3️⃣ Compile the Code

If using g++:

```bash
g++ snake.cpp -o snake
```

### 4️⃣ Run the Game

```bash
./snake
```

(On Windows, use `snake.exe`)

---

## 🎯 Controls

* W → Move Up
* S → Move Down
* A → Move Left
* D → Move Right
* X → Exit Game
